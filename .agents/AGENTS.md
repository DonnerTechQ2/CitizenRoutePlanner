# CitizenRoutePlanner - Agent Guidelines

## Технологический стек
- **Backend:** F#, ASP.NET Core, SignalR. 
- **Frontend:** Svelte (Vite), SPA без SSR.
- **Связь:** SignalR (real-time). Статика фронтенда раздаётся через `wwwroot` ASP.NET Core приложения.

## Ключевые архитектурные решения
- Приложение работает в реальном времени, парся `Game.log` игры.
- **Координаты:** Три стратегии определения локации:
  1. Прямой матч по имени в `locations-positions.json`.
  2. Математика координат (если `|x| > 10000`, ищем ближайшее небесное тело и складываем с ним локальные координаты маркера).
  3. Fallback (`UnknownLocation`) для зданий (`|x| < 10000` без точного имени).
- **Роутинг:** Используется `RouteEngine.fs`. Алгоритмы: Branch & Bound (≤12 точек), Greedy + 2-opt (>12 точек).

## Правила для агентов (AI Guidelines)
- **Следование плану:** Строго следуй `Plan.md` (находится в корне) при реализации любых новых фичей.
- **Сборка проекта:** Код должен собираться без ошибок (`dotnet build`). Не ломай F# типы!
- **Svelte:** Для фронтенда используй `npm run dev` в папке `frontend`, или собирай его в `wwwroot` бэкенда.
- **Язык общения:** Комментарии и документация на русском (как в `Plan.md`), код (переменные, функции) строго на английском.
